# Anugra Gupta Portfolio + Resume

This folder contains:
1. A professional portfolio page (`index.html`)
2. Your resume PDF (`Resume-Anugra Gupta (1).pdf`)

The portfolio links to the resume automatically.

## How to view the portfolio (and resume)

### Option A: Open directly (quickest)
1. Open this folder: `anugra_protfolio_and_resume/`
2. Double-click `index.html`
3. Click **“View Resume (PDF)”** (or **“Open Resume PDF”**)

### Option B: Run a local server (recommended)
Some browsers behave better when files are served over HTTP.
From inside `anugra_protfolio_and_resume/`, run:
```bash
python3 -m http.server 8000
```
Then open:
`http://localhost:8000/index.html`
